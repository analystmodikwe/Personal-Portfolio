# Lesedi Modikwe — Portfolio

A responsive portfolio for an AI Full Stack Software Developer with a data analytics background, focused on full-stack web applications.

## Stack

React, TypeScript, Vite, Tailwind CSS and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`; preview it with `npm run preview`.

## Edit portfolio content

Update the copy, project details, skills, contact links and workflow in `src/data/content.ts`. Place project screenshots in `public/` and set their paths and intrinsic dimensions in that data file. A CV download link is shown only when `cv` points to an existing file.
