# Lesedi Modikwe — Portfolio

A responsive portfolio for an AI Full Stack Software Developer with a data analytics background, focused on full-stack web applications.

## Stack

React, TypeScript, Vite, CSS and Three.js (loaded as a lazy hero chunk). Tailwind CSS remains available in the project toolchain.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`; preview it with `npm run preview`.

## Edit portfolio content

Update the copy, project details, skills, contact links and workflow in `src/data/content.ts`. Place project screenshots in `public/` and set their paths and intrinsic dimensions in that data file. Leave `cv` empty to keep CV buttons hidden; set it after adding a CV file.
